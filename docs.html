ROTEX Documentation

ROTEX is an AI-powered desktop app for Roblox game developers. Ask questions, generate Luau code, plan systems, and sync directly with Roblox Studio — all from one place.

ℹ️

Download: Get ROTEX at rrotex.com. The browser extension and Studio plugin are bundled with the desktop app.

Quick Start

1. Open a Project

Launch ROTEX, sign in, and click New Project. Choose Roblox as your engine and give it a name.

2. Connect Studio

Inside your project, click Install Studio Plugin — ROTEX copies the plugin into your Roblox plugins folder. Open Roblox Studio, click the Open button in the ROTEX toolbar, and paste the 6-character token shown in the ROTEX desktop app.

3. Chat with AI

Type any question in the chat panel. The AI knows which project you're in, whether Studio is connected, and what mode you're working in.

Studio Plugin

The ROTEX Studio plugin runs inside Roblox Studio and communicates with the desktop app over a local HTTP server (port 7878). It lets the AI know your Studio session is live, so answers are context-aware.

⚠️

The token regenerates each session. If Studio disconnects, copy the new token from the desktop app and re-enter it in the plugin panel.

Rojo Sync

Click Rojo Connect inside the plugin panel to start a Rojo dev session. The AI will see whether Rojo sync is running and can give advice accordingly.

AI Model Overview

Fast FREE

Groq Llama 3.1 8B Instant. Best for quick one-liners, simple script fixes, and fast lookups. Lowest TexToken cost.

Balanced FREE

Groq Qwen3 32B. Good balance of speed and quality. Great for mid-size coding tasks and explaining systems.

Smart FREE

Groq Llama 3.3 70B. Best free-tier model for complex debugging, architecture planning, and detailed explanations.

Claude Haiku FREE

Claude Haiku 4.5. The highest quality model. Best code, best reasoning. Available to everyone and costs more TexTokens.

TexBrain 0.5-β LOCAL · FREE

Runs entirely on your machine via Ollama — completely free, no TexTokens, no rate limits. Requires Ollama installed. Uses a three-agent pipeline: a clarifier expands your request, a worker generates the response, giving you higher quality answers from local hardware.
