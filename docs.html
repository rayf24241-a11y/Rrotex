ROTEX Roblox Dev Mode

ROTEX is now a web-first Roblox Studio AI console. The website chats with the Studio plugin through a bridge code, reads live scripts/UI context, and queues real edits back into Studio.

Quick Start

  1. Open rrotex.com and sign in.
  2. Copy the bridge code shown in the Studio Link panel.
  3. Open the ROTEX Roblox Studio plugin, paste the code, and click Connect.
  4. Use Ask for questions, Agent for normal edits, and Supreme for deep multi-step fixes.

If the plugin says HTTP requests are disabled, enable Game Settings > Security > Allow HTTP Requests in Roblox Studio.

What The Plugin Can Do

Edit scripts

ROTEX applies hidden file: blocks to the correct Roblox service root.

Create visible UI

It can build StarterGui trees and LocalScript owners so UI actually shows in play mode.

Build worlds

It can create model geometry, edit terrain, set lighting, and insert Toolbox assets for map/world building.

Fix bugs

It sends Studio errors and fresh context back to the web app so the AI can repair the real owner script.

Modes

  • Ask: answers questions and explains Roblox concepts. It does not edit Studio.
  • Agent: makes focused Roblox edits with executable script/action blocks.
  • Supreme: does deeper planning, duplicate cleanup, UI visibility checks, and multi-file changes when needed.
